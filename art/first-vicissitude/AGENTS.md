# 美术优化的持续约定

用户于 2026-09-23 再次明确：优化必须借鉴优秀大型首领模型的结构方法，在减少几何开销的同时保留视觉细节。接续、上下文压缩或更换实现工具后，仍须遵守以下方向。

## 每轮实际优化

1. 先查用户指定的参考材料，优先查 Downloads 中已下载的源码与资源。分析对应部位的基础体块、甲片叠层、关节连接、薄片/实体选择、UV 展开和贴图分工。不能只引用总面数，或把减少圆周截面数当成参考分析的全部。
2. 把参考方法转化为本项目自己的结构设计。不得直接复制外部代码、纹理或模型资源；设计文档不出现具体参考模组、首领名称或来源链接。需要说明具体来源时在对话中说明。
3. 修改前保存可对照的模型与预览。先确定哪些轮廓、力量感、负空间、连接关系和材质特征必须保留，再决定哪些几何可以合并、简化或转由贴图表达。
4. 减面与贴图补偿是同一项工作。去掉的倒角、凹槽、叠压或骨脊原先产生的阴影变化，应在正确的表面 UV 上补充接触暗部、亮面过渡、材质边缘和必要刻纹。若已有贴图足以表达，检查并说明依据；不能默认旧图会自动补偿形体变化。
5. 进行同机位、同姿态、同光照、同输出尺寸的前后对照，兼看普通光照和无灯光材质、正侧背面、两阶段及相关动作。近处检查细节，较远处检查整体可读性。离线图不得冒充游戏截图。
6. 用户举出的“保留约 80% 细节”是视觉保留目标的例子，不是已锁定的数值门槛，也不是像素相似率或保留 80% 三角面。没有定义评价方法和证据时，不声称达到某个保留百分比。核心轮廓与设计特征不能用总体比例抵消。
7. 若减面造成明显退化，继续调整图稿/结构，必要时恢复关键几何；不要为了达到面数指标交付劣化版本。少改几面不是失败，单纯面数下降也不是验收通过。
8. 汇报具体结构变化、贴图如何补回细节、前后网格与三角面数量，以及仍可见的损失和未验证项。分开统计几何减少、顶点提交减少和实际帧率，不把它们互相替代。

## 保留的项目方向

- 保持原有失败圣性残骸主题、晶体头、真实胸洞与同心环、无腿结构，以及一阶段羽翼转二阶段骨翼和落羽转场。
- 已获肯定的肩臂力量感、翼部伸展轮廓、胸环位置及逐表面纹理方向作为比较基线。
- 左右臂与对应左右翼优先复用 UV；同一部件的正背、侧壁和断面按需要独立展开。禁止用重复小格或简单放大贴图冒充细节提升。
- 阅读本目录 README 和 `docs/design/first-vicissitude` 的最新记录；历史面数不是最终预算。必要修订不要求重新向用户确认已经授权的优化工作。
