# 无常两阶段血条

2026-10-12 用户确认原有华丽造型方向，撤去简化重设计，继续细化像素明暗。
保留晶体头、金纹、叠层肩甲、密集羽片、骨翼枝刺和两端装饰；按用户要求移除血条中头后的缺口圆环。
一阶段覆羽覆盖血槽，二阶段脱羽露出两侧血槽，中央装饰仍覆盖中段。
调整重点是羽片接触暗部、浅紫中间调、骨翼连续边缘光和晶体明暗面；后续不得把这一方向误解成删减装饰。

- `phase-one-master.png`、`phase-two-master.png`：内置 `image_gen.imagegen` 生成的透明图稿原件。
- `prompts.txt`：完整提示词；本轮以原版两阶段图稿作明暗精修，再移除头后圆环。
- 外部参考仅用于分析像素 HUD 的布局和表现方法，不复制图案。

运行 `python art/first-vicissitude/tools/make_boss_bar.py`，裁切时保留原圆环上沿的留空，
避免移除圆环后把剩余图案放大。RGB 使用预乘透明度的面积采样，保留连续明暗面；
轮廓透明度仍用最近邻采样，保留二值透明像素。针对实机粗糙问题，现从原稿直接输出两倍分辨率，
取消 24 色量化；每个 GUI 像素对应 2×2 贴图像素，保留羽片暗缝与金纹，屏幕占位不变。
本轮通过内置 imagegen 重绘色块：强化羽片叠压暗缝、分开晶体明暗面，将细密金纹归并成少量主纹。
512×64 的贴图像素数为上一版 1024×128 的四分之一；细线与曲线平滑度有所取舍，并不宣称细节无损。
脚本重新生成四张游戏 PNG，图稿原件不变。

| 项目 | 规格 |
| --- | --- |
| 底条贴图 | 256×16；空槽与填充各 182×5 |
| 装饰贴图 | 512×64；实际图案 384×60，位于贴图 (64,2) |
| 装饰绘制大小 | 256×32 GUI 像素；图案仍占 192×30，位于 GUI (32,1) |
| 血槽在装饰层内的位置 | GUI (37,19)；上下轨及中央件保持原构图 |
| 底条相对事件坐标 | (0,19) |
| 装饰层相对事件坐标 | (-37,0)；和屏幕中央及原版 182px 血条居中对齐 |
| 名称 | 原版位置 y-9，位于图稿上方 |
| 多条血条间距 | 43px；含名称高度与 2px 间隙 |

一阶段客户端只绘制名称与覆羽图稿，不绘制底条/填充，羽片间的负空间不会透出血量。
二阶段使用现有 `LerpingBossEvent` 进度绘制填充；服务端血量、阶段同步和切换时机不变。
