# 渡鸦

实体 ID：`maledict:raven`。刷怪蛋：`maledict:raven_spawn_egg`，已加入咒邪创造模式物品栏。

渡鸦模型和身体贴图为本项目原创。羽毛投射物使用用户提供的 16×16 透明 PNG，保持原文件不变。
实现参考 [Alex's Mobs ModelCrow](https://github.com/AlexModGuy/AlexsMobs/blob/1.20/src/main/java/com/github/alexthe666/alexsmobs/client/model/ModelCrow.java)
的部件层级、左右翼轴点、姿态重置与飞行进度插值，以及
[EntityCrow](https://github.com/AlexModGuy/AlexsMobs/blob/1.20/src/main/java/com/github/alexthe666/alexsmobs/entity/EntityCrow.java)
的地面/空中导航切换思路；没有复制模型坐标、贴图或 Citadel 动画实现。暮色森林模型文件未成功取得，没有用作已验证参考。

`RavenModel` 使用原版 `ModelPart`，16 模型单位等于一格。展开宽 48、长 32、高不超过 16 单位；
收拢宽 16、长 32、高 16 单位。碰撞/寻路使用身体的 1×1 格方形范围。
翅膀各有 7 根初级飞羽和 4 根次级飞羽，尾部有 5 根组成楔形的尾羽。

普通生命系统，默认生命 10、护甲 4。属于 Vicissitude 的 `MobType`，没有继承首领的生命池或限伤。
和平/简单/普通/困难攻击分别为 2/4/6/8，对亡灵为 4/8/12/16。亡灵伤害每次固定减半，然后结算护甲；
箭矢按造成伤害的射手判断。不会把其他渡鸦作为目标，误伤仍按普通受伤结算。

绯红森林和下界荒地自然生成配置为每群 4–6 只、权重 12。沿用原版群体生成，实际成功数量受附近可生成空间影响。
不可驯服，对玩家保持中立，被攻击时还击，主动寻找亡灵。飞行使用 `FlyingPathNavigation`，
落地使用 `GroundPathNavigation`，空闲时跳行、短途飞行或两只结伴。免疫坠落伤害，保留原版传送门穿越，
没有主世界生存限制。掉落表为空。

地面跳跃由原版跳跃阶段处理，起跳速度为 0.50，普通地面无效果时理论跳高约 1.71 格。
空闲飞行保留地面落点，落点抬高到地面上方 4–6 格，结束后先慢速寻路下降，接近时制动并对齐落点，接触地面才收翼。
战斗结束后的降落会寻找附近有支撑、无液体且容得下身体的落点。

灵魂沙不降低渡鸦的移动速度。地面目标的水平距离超过 4 格时起飞，飞进 2 格范围后寻找
目标附近的安全落点，落地后再跳行接近；例如 8 格外的腐肉：起飞 → 飞到附近 → 落地 → 吃。
这套规则用于觅食、结伴、幼鸟跟随亲鸟、靠近繁殖对象和地面闲逛，战斗与跟随信任玩家仍使用原有飞行方式。

踩火、熔岩、岩浆块、点燃的营火等危险位置，或受到火焰、仙人掌、甜浆果丛的环境伤害时，
最高优先级的避险动作会打断悬停、降落、觅食与跟随，先起飞离开危险。紧急移动选取碰撞检查通过的
附近安全位置，直接飞出危险起点，避免普通寻路把火周围节点拒绝后无法开始移动。
离开危险至少 3 格且身体不再接触伤害方块后恢复原行为，生物攻击目标保留，正常还击。
身上的剩余燃烧仍按原版结算，但不会每次掉血都重新逃跑；再次接触危险或熄灭后重新着火会再次避险。
降落点和悬停射击站位同样排除身体及脚下接触的伤害方块。

被带生物实体的伤害打中时（近战、箭、雪球、爆炸等），渡鸦先起飞脱离近战距离再还击：
打断悬停、降落与地面移动，爬升到攻击者脚底上方 4 格，同时至少比挨打时高 1 格，水平速度衰减到 60%。
到达高度或最多 40 tick（2 秒，例如头顶被方块挡住）后结束，攻击目标保留，恢复原有的追击、悬停与射击。
爬升期间再次挨打只延长计时、不会降低目标高度。环境伤害不带生物实体，不会触发爬升；
踩火等危险避险开始时立即取消爬升，两者的优先级不变。

## 腐肉、繁殖与信任

受伤时会寻找并吃掉附近地上的腐肉，也接受玩家手持腐肉投喂，每枚恢复 2 点生命。
成年渡鸦 6/10 → 8/10 → 10/10，满血后下一枚才使它进入繁殖状态；繁殖冷却中满血不消耗腐肉。
地上的腐肉只用于回血。玩家投喂幼鸟还会按原版动物规则加速长大。

两只成年渡鸦繁殖产生幼鸟。玩家 A、B 分别投喂双亲时，幼鸟信任 A 和 B；同一人投喂只记一次。
信任随存档保存，成年后保留，信任玩家的渡鸦不会自然消失，也不会还击这些玩家。
投喂野生成鸟不会使它获得信任，仍不可驯服。

信任玩家的渡鸦会飞行跟随，并在玩家落地、肩膀有空位时停肩，幼鸟和成鸟均可。
水平距离超过 8 格时飞向玩家上方 4 格，进入 8 格内降回上方 1 格，保证仍能贴近并停肩。
仅肩膀显示缩小：成鸟为原尺寸的 40%，幼鸟为 30%；世界中幼鸟为成鸟尺寸的 50%。
肩膀使用原版左右肩 NBT 保存完整生命、年龄与信任，幼鸟在肩上继续长大。
玩家潜行可让渡鸦离肩；受伤、入水等原版离肩条件同样生效。离肩后有 5 秒停肩冷却。

## 悬停振翅与羽毛射击

敌人在 3–12 格内且可见时，渡鸦升空停住，在固定位置振翅；悬停点定在敌人脚底上方 4 格，并且不会低于
当前高度。原版近战判定量的是「怪物中心到目标脚底」的直线距离，1 格宽的渡鸦在僵尸面前 1.56 格、
蜘蛛或疥猪 2.97 格、劫掠兽 4.02 格内才会挨打，4 格高度已避开所有会主动猎杀渡鸦的近战怪物；
敌人走到正下方时三维距离仍有 4 格，不会触发「贴近 3 格」而中断悬停俯冲近战。抬高后的悬停点要重新过
碰撞与伤害方块检查，并确认从那里仍能射中目标（射线被方块或无关生物挡住就不采用，避免升上去再降下来
来回换位）；新站位不可用时保留原悬停点继续射击，连当前位置都不行才换位或近战。
首次蓄力 10 tick（0.5 秒），随后每隔 60 tick（3 秒）射出一根羽毛，并持续悬停。敌人贴近 3 格、
超出射程或被遮挡时，中止蓄力与悬停，恢复追击和近战。失去目标后正常降落。

羽毛实体 ID 为 `maledict:raven_feather`，直线飞行，无重力；释放时记录渡鸦的攻击属性和难度，
命中时使用与近战相同的 `RavenCombat.attackDamage`。默认四档难度伤害 2/4/6/8，对亡灵为 4/8/12/16，
按正常受伤与护甲流程结算，命中效果沿用渡鸦近战。亡灵对渡鸦造成的伤害仍每次固定减半。
羽毛穿过其他渡鸦与发射者信任的玩家，命中一次或撞墙后消失，未命中时最多存在 60 tick；不会掉落物品。

射线被方块或无关的非亡灵生物挡住时，优先寻找目标侧面或上方可到达、无碰撞的空中站位，
换位后才悬停蓄力，每次发射前再次检查完整射线，找不到安全角度就不发射。
羽毛仍可还击非亡灵攻击者；释放时保存目标 UUID，其他非亡灵即使突然闯入也会被羽毛穿过。
例如牛挡在渡鸦和僵尸之间：原位置禁止射击 → 侧飞或抬高 → 射线安全后蓄力 → 发射；
牛在发射后闯入：羽毛穿过牛，继续飞向敌人。其他渡鸦和信任玩家始终排除，亡灵仍可被命中。

悬停动画加快并增大左右翼的对称振幅，收紧双腿，增加身体与尾羽的轻微起伏。
姿态在普通飞行与悬停之间平滑过渡，实际移动用固定悬停点校正，不保留巡航惯性。

## 可重复生成

使用 Java 17，在项目根目录运行贴图生成器：

```powershell
java art/raven/tools/RavenTextureBuilder.java
```

预览调用实际 `RavenModel.createBodyLayer().bakeRoot()`，使用模型渲染器输出的顶点与 UV，
不维护另一份近似几何。运行后检查尺寸并输出 `preview/raven.png`，同时直接调用模型的
`applyFlightPose` 生成悬停上下振翅姿态 `preview/raven-hover.png`：

```powershell
gradle -I art/raven/tools/preview.init.gradle ravenPreview --offline
```

该图片为软件模型预览，不是游戏截图。语言、刷怪蛋模型、掉落表和群系生成资源由 `runData` 生成。

## 验证

已通过 Java 编译、30 项渡鸦攻击/减伤、投喂、信任、地面移动、悬停射击、飞行高度/受击爬升、安全射线与环境避险规则测试、`runData`，以及实际烘焙模型的尺寸检查和悬停上下振翅预览。
游戏中的寻路、自然生成、成对闲逛、跨维度和肩膀显示尚需实际游玩验证：

1. `/give @s maledict:raven_spawn_egg`，检查名称、配色、生成和创造模式物品栏。
2. 生成渡鸦和骷髅/僵尸，观察主动追击、空中绕障和不同难度下的攻击。
3. 生成普通动物与玩家，确认渡鸦只在受攻击后还击；让渡鸦误伤另一只，确认不互相攻击。
4. 在绯红森林和下界荒地留出生成空间，观察自然群体生成和地面跳行、结伴；击杀确认无物品掉落。
5. 将渡鸦引入下界传送门，确认到主世界后正常行动；从高处释放确认无坠落伤害。
6. 将成年渡鸦生命设为 6，连续投喂三枚腐肉，确认先恢复至 8、10，再出现繁殖爱心；地上腐肉只回血。
7. 两位玩家分别喂两只满血亲鸟，确认幼鸟信任并跟随二人，成鸟接受投喂仍不信任；投喂幼鸟加速长大。
8. 检查幼鸟/成鸟停肩缩放，潜行与受伤离肩、左右肩双鸟、保存重载后的生命和信任，以及幼鸟在肩上长大。
9. 比较灵魂沙与普通地面的移动速度；让受伤渡鸦寻找 8 格外的腐肉，检查先飞、落地再吃，以及同样距离下的结伴、跟随亲鸟和繁殖。
10. 在 8 格外放置僵尸/骷髅，观察升空后原地振翅、首次 0.5 秒蓄力和每 3 秒一根的持续射击；检查目标贴近、遮挡、逃远与死亡后的状态切换。
11. 检查四档羽毛伤害、对亡灵翻倍、碰墙消失、不产生掉落物，以及羽毛穿过其他渡鸦与信任玩家。
12. 让牛挡在渡鸦与僵尸之间，检查换位后才发射、没有安全角度时不发射；让牛在发射后闯入，确认不受伤；玩家攻击渡鸦仍可受到其羽毛还击。
13. 在火、灵魂火、岩浆块、点燃的营火与熔岩边缘测试地面/悬停渡鸦，确认立即打断动作起飞避险，离开后恢复；确认不会降落到伤害方块上，余火掉血不反复触发逃跑，生物攻击照常还击。
14. 在 8 格外放置僵尸，确认悬停点明显高于僵尸头顶、僵尸走到正下方也够不到，且悬停不再因贴近 3 格中断；用弓箭或另一只生物打中渡鸦，确认它先向上窜一段再恢复射击；在树林与洞穴里确认抬高后的悬停点被挡住时仍保留原悬停点，而不是掉回近战。
15. 让渡鸦跟随信任玩家，确认 8 格外飞得较高、靠近后降到肩高并能停肩；观察空闲飞行落点比地面高 4–6 格后仍能正常降落。
