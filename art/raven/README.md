# 渡鸦

实体 ID：`maledict:raven`。刷怪蛋：`maledict:raven_spawn_egg`，已加入咒邪创造模式物品栏。

模型和贴图为本项目原创。实现参考 [Alex's Mobs ModelCrow](https://github.com/AlexModGuy/AlexsMobs/blob/1.20/src/main/java/com/github/alexthe666/alexsmobs/client/model/ModelCrow.java)
的部件层级、左右翼轴点、姿态重置与飞行进度插值，以及
[EntityCrow](https://github.com/AlexModGuy/AlexsMobs/blob/1.20/src/main/java/com/github/alexthe666/alexsmobs/entity/EntityCrow.java)
的地面/空中导航切换思路；没有复制模型坐标、贴图或 Citadel 动画实现。暮色森林模型文件未成功取得，没有用作已验证参考。

`RavenModel` 使用原版 `ModelPart`，16 模型单位等于一格。展开宽 48、长 32、高不超过 16 单位；
收拢宽 16、长 32、高 16 单位。碰撞/寻路使用身体的 1×1 格方形范围。
翅膀各有 7 根初级飞羽和 4 根次级飞羽，尾部有 5 根组成楔形的尾羽。

普通生命系统，默认生命 10、护甲 4。属于 Vicissitude 的 `MobType`，没有继承首领的生命池或限伤。
和平/简单/普通/困难攻击分别为 2/4/6/8，对亡灵为 4/8/12/16。亡灵伤害每次固定减半，然后结算护甲；
箭矢按造成伤害的射手判断。不会把其他渡鸦作为目标，误伤仍按普通受伤结算。

绯红森林和下界荒地自然生成配置为每群 4–6 只、权重 12。沿用原版群体生成，实际成功数量受附近可生成空间影响。
不可驯服，对玩家保持中立，被攻击时还击，主动寻找亡灵。飞行使用 `FlyingPathNavigation`，
落地使用 `GroundPathNavigation`，空闲时跳行、短途飞行或两只结伴。免疫坠落伤害，保留原版传送门穿越，
没有主世界生存限制。掉落表为空。

地面跳跃由原版跳跃阶段处理，起跳速度为 0.50，普通地面无效果时理论跳高约 1.71 格。
空闲飞行保留地面落点，结束后先慢速寻路下降，接近时制动并对齐落点，接触地面才收翼。
战斗结束后的降落会寻找附近有支撑、无液体且容得下身体的落点。

## 腐肉、繁殖与信任

受伤时会寻找并吃掉附近地上的腐肉，也接受玩家手持腐肉投喂，每枚恢复 2 点生命。
成年渡鸦 6/10 → 8/10 → 10/10，满血后下一枚才使它进入繁殖状态；繁殖冷却中满血不消耗腐肉。
地上的腐肉只用于回血。玩家投喂幼鸟还会按原版动物规则加速长大。

两只成年渡鸦繁殖产生幼鸟。玩家 A、B 分别投喂双亲时，幼鸟信任 A 和 B；同一人投喂只记一次。
信任随存档保存，成年后保留，信任玩家的渡鸦不会自然消失，也不会还击这些玩家。
投喂野生成鸟不会使它获得信任，仍不可驯服。

信任玩家的渡鸦会飞行跟随，并在玩家落地、肩膀有空位时停肩，幼鸟和成鸟均可。
仅肩膀显示缩小：成鸟为原尺寸的 40%，幼鸟为 30%；世界中幼鸟为成鸟尺寸的 50%。
肩膀使用原版左右肩 NBT 保存完整生命、年龄与信任，幼鸟在肩上继续长大。
玩家潜行可让渡鸦离肩；受伤、入水等原版离肩条件同样生效。离肩后有 5 秒停肩冷却。

## 可重复生成

使用 Java 17，在项目根目录运行贴图生成器：

```powershell
java art/raven/tools/RavenTextureBuilder.java
```

预览调用实际 `RavenModel.createBodyLayer().bakeRoot()`，使用模型渲染器输出的顶点与 UV，
不维护另一份近似几何。运行后检查尺寸并输出 `preview/raven.png`：

```powershell
gradle -I art/raven/tools/preview.init.gradle ravenPreview --offline
```

该图片为软件模型预览，不是游戏截图。语言、刷怪蛋模型、掉落表和群系生成资源由 `runData` 生成。

## 验证

已通过 Java 编译、渡鸦攻击/减伤、投喂次序与繁殖信任规则测试、`runData`，以及实际烘焙模型的尺寸检查。
游戏中的寻路、自然生成、成对闲逛、跨维度和肩膀显示尚需实际游玩验证：

1. `/give @s maledict:raven_spawn_egg`，检查名称、配色、生成和创造模式物品栏。
2. 生成渡鸦和骷髅/僵尸，观察主动追击、空中绕障和不同难度下的攻击。
3. 生成普通动物与玩家，确认渡鸦只在受攻击后还击；让渡鸦误伤另一只，确认不互相攻击。
4. 在绯红森林和下界荒地留出生成空间，观察自然群体生成和地面跳行、结伴；击杀确认无物品掉落。
5. 将渡鸦引入下界传送门，确认到主世界后正常行动；从高处释放确认无坠落伤害。
6. 将成年渡鸦生命设为 6，连续投喂三枚腐肉，确认先恢复至 8、10，再出现繁殖爱心；地上腐肉只回血。
7. 两位玩家分别喂两只满血亲鸟，确认幼鸟信任并跟随二人，成鸟接受投喂仍不信任；投喂幼鸟加速长大。
8. 检查幼鸟/成鸟停肩缩放，潜行与受伤离肩、左右肩双鸟、保存重载后的生命和信任，以及幼鸟在肩上长大。
