# 腐枯界 / The Blighted Realm

## 已确认的初版

腐化接近终局、天象仿佛凝滞的主世界。保持主世界式连续地形、山川、河海、洞穴与正常生存活动。
首版仅 `maledict:blighted_wastes` 一个群系，在其内部通过植被分布形成荒地与灵魂木林地。
不冻结世界时钟、实体、方块更新或植物生长。

- 维度 ID：`maledict:blighted_realm`。天象固定在午夜，无太阳、月亮、星辰、云及天气变化。
- 保留原版地形噪声、含水层、洞穴、矿物和普通生物；草地与浅层泥土改为 Malum 腐枯材料。
  地形默认实心方块改为污秽石 `malum:tainted_rock`，深层改为扭曲石 `malum:twisted_rock`；
  沿用原版 Y=0 至 8 的深层过渡，Y≤0 为扭曲石，Y≥8 的主体为污秽石，不仅替换山坡表面。
  去掉额外的原版花岗岩、闪长岩、安山岩、凝灰岩团块特征；矿脉自身的伴生岩保留原版行为。
  污秽石加入 `minecraft:stone_ore_replaceables`，扭曲石加入 `minecraft:deepslate_ore_replaceables`，
  两者加入 `minecraft:base_stone_overworld`，以保留矿石与基于基础石材的特征替换。
- 腐枯界的两项原版金矿生成改为恶念之铅矿石，沿用原本金矿的高度分布、生成次数、矿团大小与空气暴露限制。
  污秽石、扭曲石各有一种宿主外观，均掉落同一种恶念之铅碎片；普通挖掘掉 1 碎片，时运增产，精准采集掉矿石本身。
  铁镐及以上可采集。8 个碎片无序合成 1 个 Malum 已有的恶念之铅；不新增普通铅资源。
  其他原版矿石及主世界金矿生成保持原规则；已生成区块不回填替换。
- 树木复用 Malum 灵魂木生成器；地面植物使用腐枯生长物。草、叶、水、天空和雾使用灰紫至黑紫色。
- 不给整个画面染色，不覆盖 Malum 公共贴图，不改变其他维度中相同方块的颜色。
- 群系加入 `minecraft:is_overworld`，接受以此标签为条件的生成；原版要塞标签已引用它，因此要塞自动获得准入。
  `MaledictBiomeTags#addTags` 仅添加此分类，再由 `runData` 输出；不另行添加具体结构的群系标签。
  `is_overworld` 是群系分类，不继承主世界的完整生成配置。原版结构按各自 `has_structure/*` 标签筛选群系，
  是否准入由原有标签引用关系决定。仅匹配此分类仍须满足生成器、维度、高度及地形等规则的其他条件。
  矿物、洞穴、植被和生物分别由 `MaledictWorldgen` 的生成配置与生成列表显式设置。
- 平原动物在本维度可使用腐枯地面生成；其他维度的生物生成条件保持原样。
- 不能睡眠或绑定重生点；床、重生锚交互提示失败，不爆炸。物品地图的紫色不在初版范围。

## 已确认的井传送模型

主世界 **16 格 = 腐枯界 1 格**。只换算首次建井候选点的 X/Z，Y 由安全地形决定。
例：主世界 `(1600, y, -800)` 对应腐枯界 `(100, y', -50)`，允许为安全落点避让。

1. 允许人工入口，只替换 Malum 原本即将执行的完整受拒流程，不验证完整井体。
2. 主世界准入：服务端 `delusion` 槽实际装备一个有效装备槽仅为 `delusion` 的物品。
   不限定物品 ID、阶段或客户端渲染开关。空槽、背包物品、其他槽装备和多槽通用饰品均不授予资格。
3. 未配对井在另一端自动生成 Malum 原生井结构，并保存世界级双向配对；已配对井永不被其他入口抢占。
4. A↔X、B↔Y：从 A 进入后步行至 Y，再跳井，返回 B。玩家自己的上一次来源不覆盖井的配对。
5. 两边均沿用入井、下沉与约 61 tick 的原接触累计。回程无需保留装备；腐枯界人工未配对井可在主世界建对应井。
6. 到达目的井口后复用 Malum `rejection = 40` 的上浮动作、`currentAffliction = 100` 的黑幕及其原生消退。
   不调用 `reject` 或 `VoidRejectionPacket`，不授予受拒药水、伤害、启示或首次受拒奖励。
   上浮时轻推向已验证的井沿，避免静止落回井液；首次落地免摔伤，保护最多持续 100 tick。
7. 冷却由服务端持久化控制，80 tick 内不再传送。客户端用 Malum 自有 capability 同步接收出井状态。
8. 主世界或腐枯界目的井被拆除时，都先在原目标附近重建，再更新该对井的对应端。
   例：A↔X、B↔Y，拆除 A 后从 X 返回会重建 A′，保存为 A′↔X，B↔Y 不变；旧 A 的配对记录移除。
   重建保持原目标 X/Z 附近，Y 依据安全地表重新选取；浅层地基不足时抬高井体，避免穿过基岩。
   入境建井失败保留原拒绝；回程建井失败才退回已验证的主世界绑定出生点或世界出生点附近。

落点按实际碰撞形状验证，包括腐枯土的 14/16 高度。生成井避让已有配对井、方块实体及非自然建筑方块，
不保持远端区块永久加载。

## 扩展点与实现边界

本地依赖 Malum `1.20.1-1.6.7` 的入口为 `TouchOfDarknessHandler.reject(LivingEntity)`。
其拒绝网络包与状态修改发生在伤害、药水事件之前，没有拒绝前的可取消扩展点。
因此只在该方法 HEAD 窄注入；不覆写 tick，不改变未满足条件的拒绝流程。

腐枯界抑制微光视觉的灰度提亮；保留视界槽黑暗免疫及其异常遮挡雾处理，正常空气距离雾继续保留。
离开维度后恢复微光视觉。天空特效仅按本维度的 effects ID 注册。

所有维度、群系、噪声、特征、标签及本地化资源由 `runData` 生成，不直接修改 `src/generated`。

## 验证

`BlightedRealmTest` 在实际 Forge 服务端验证资源加载、16:1 与负坐标、独立井对的 NBT 往返、
真实 Curios 装备权限、原始拒绝、Mixin 入口、建井与卸下装备后的回程、冷却、原生出井状态、
一次摔伤保护、14/16 落点、出生点禁用与局部动物生成适配。
这些服务端场景不替代客户端的天空、黑幕、浮出手感及不同图形设置的实际视觉验收。
