# 巨匠造物主攻击

2026-11-02确认：接入正常战斗AI；当前冲撞、激光和泪雨基础伤害分别为7、6、5点，最终伤害按难度倍率计算。

- 冲撞保持昂首，蓄势时朝向目标，释放后沿锁定方向直冲。动画驱动的头、身体、尾巴碰撞箱均参与命中；同一tick中多个部位重叠接触同一目标时合并为一次探针调用。伤害入口不再预先过滤无敌帧，由所选ChangeLib路径处理；不保留整次冲撞的命中记录。
- 双眼激光蓄能后缓慢追踪。头部相对身体最多左右转60°、上下转75°，身体继续转向追赶目标；客户端光束和服务端伤害均直接使用当前头部骨骼的正面方向，避免反向光束钻出后脑。光束由方块碰撞形状截断，命中生物造成伤害并刷新100tick的 `malum:silenced`，不叠加等级。双眼每个伤害拍共用命中记录。
- 原地抬头张口吼叫，召唤哭泣黑曜石般的紫色泪雨。准备起手时，当前目标必须是头部中心水平5格内的可攻击玩家；否则跳过本招、继续选择其他招式。通过检查后，将落区锁定为起手时头部中心的水平半径5格圆盘；玩家随后跑出范围或目标追踪结束，仍照常完成释放和收势，落区不跟随头部动作或目标移动。每滴沿真实下降轨迹判定生物命中，方块和屋顶不阻挡。登场唤醒不做玩家距离检查，同样锁定头部中心的5格圆盘，持续至原有100tick唤醒结束，存档保留该落区。

具体序列：同tick头部与身体同时接触A→只进入一次探针；下tick尾巴仍接触A→可再次进入探针。激光遇墙→墙后A没有伤害或静默；移开墙→下一伤害拍可命中A并刷新静默。玩家离头部正下方6格→不选泪雨，4格→可起手并锁定圆盘，此后玩家退到6格→仍按原圆盘降雨。雨滴穿过屋顶→交到A的碰撞箱→按难度伤害命中，该滴消失。

招式间隔40tick，依次使用冲撞、激光、满足近身条件的吼叫；追踪48格内的生存玩家，也会反击攻击者。远于28格时先寻路接近；冷却期间继续接近较远目标，近处则沿缓弯调整站位，每5tick检查站位，沿用尾身避让与接触拆墙。基础移动速度0.30，巡游与近处调整站位的速度系数1.0；已有实体重载时也应用新基础速度。非战斗巡游每10tick尝试选点，保留短暂停留。方块不会禁止整套招式开始，激光自行截断、冲撞遵循接触拆墙、泪雨穿过方块。沉睡、唤醒和展开阶段不发动战斗招式。冲撞前5tick逐渐加速至0.8格/tick，伤害结束后用10tick减速滑行，收速期间不再造成冲撞伤害。激光最长40格，泪雨半径5格、每tick8滴、下降速度0.9格/tick、每滴最多存在30tick。

护甲10。每击上限为 3% 最大生命，在护甲前截断后过 10 甲：简单/普通/困难约 10.1/16.6/22.1。普通 7–9 伤害的武器打不到 12/18/24 的上限，仍只按 10 甲减伤。简单、普通、困难首次生成的生命池分别为400、600、800，沿用基类的每UUID持久化账本，存档中保留生成时的血量难度。伤害使用当前世界难度：基础值×倍率，简单0.5、普通1、困难1.5，和平为0。三招分别配置 `demiurge.chargeDamage`、`laserDamage`、`rainDamage`；比例配置 `easyDamageMultiplier`、`normalDamageMultiplier`、`hardDamageMultiplier`。这些项目位于 `maledict-common.toml`，修改基础值后各难度按比例变化；原版玩家伤害不再额外缩放一遍。

三招统一按世界难度选择ChangeLib伤害方法：简单为LIGHT（`lighterDamageMethod`），普通为MEDIUM（`mediumDamageMethod(..., false)`），困难为FINAL（`finalDamageMethod(..., finalNoRemove(), false)`），均不追伤：第一条路径已有真实扣血后，不再补足护甲、减伤等削去的差额。按用户确认保留已删除的入口无敌帧过滤。

Malum实体精魂数据为神圣6、邪恶7、邪术8、幽影3，主精魂为邪术。与腐枯凋灵一样通过原生精魂获取流程产出。

Blender逐tick导出的三段姿态与唤醒、蛇行共用同一模型；招式以静止蛇行姿态为参考，作为增量叠加到当前实际行进相位，避免切换时身体复位。整个蓄势、收势时段使用平滑混合；昂首冲撞的颈部回收与前探、激光蓄能的抬头、吼叫的张口均加大幅度。休息时保留轻微呼吸和摆头，但不推进依靠行进距离的身体相位。公共端 `DemiurgeRig` 同时驱动渲染、分段碰撞箱与双眼发射位置。战斗状态与起始时间通过实体数据同步，加载存档时终止未完成的战斗招式；唤醒的持久化时间线保持原有规则。

发光遮罩从原有纹理的紫色像素逐点派生，也包含身体上较暗的紫色纹路；将这些像素的发光颜色提亮至最多原值的3倍，保留色相。原贴图、UV和纹路宽度不变，不采样或扩展相邻像素。亮度沿身体分段脉动；唤醒和施法逐渐增强，收势逐渐退到微弱的呼吸亮度。

## 断尾、死亡与掉落（2026-11-02 确认）

巨匠的蛇身按血量分档失去长度，只减不增：

| 血量比例 | 断掉的尾段 |
| --- | --- |
| > 75% | 0 |
| ≤ 75% | 4 |
| ≤ 50% | 8 |
| ≤ 25% | 11（请求 12，被上限截到 11） |

- 尾段从链条末端整节切除：先失去 4 节尾骨，再依次失去低盘骨节；断口仍保留最后一节完整碰撞箱，其余被切掉的骨节既不再渲染也不再参与分段碰撞。断尾量写入同步数据并随存档保存，治疗不会让它长回来。
- 上限由编舞数据决定：地上蛇身至少留 8 格，因此最多只能切 11 节（剩余尾端在全部蛇行帧里最少约 8.6 格）；再切一节只剩约 7.7 格，会跌破 8 格下限。
- 每切一档在断口生成灰尘与白烟粒子并播放石头碎裂声；巡游自避让的走廊也缩短到当前尾端，断掉的尾巴不再挡自己的路。

死亡动画共 80 tick：前 20 tick 紫色发光熄灭，头部同时冒出紫色魂火（沿用原版魂火粒子，贴图不变、顶点色染紫）；0–40 tick 石像顶点色压到接近纯黑；38–76 tick 按稳定哈希顺序逐面飞散，同时沿剩余骨节持续散落灰烬，76 tick 后模型完全消失，80 tick 时移除实体并播放原版死亡粒子。死亡期间不再绘制眼睛激光。

死亡必定额外掉落一枚“光的残片”（`maledict:light_fragment`），走与下界之星相同的 `spawnAtLocation` + `setExtendedLifetime` 路径，不受抢夺和战利品表影响。该物品暂无专属贴图，暂用腐枯之星贴图占位。
