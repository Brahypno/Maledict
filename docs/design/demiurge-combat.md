# 巨匠造物主攻击

2026-11-02确认：接入正常战斗AI；冲撞、激光和泪雨基础伤害暂为1点，最终伤害按难度倍率计算。

- 冲撞保持昂首，蓄势时朝向目标，释放后沿锁定方向直冲。动画驱动的头、身体、尾巴碰撞箱均参与命中；同一tick中多个部位重叠接触同一目标时合并为一次伤害尝试，处于原版等额伤害无敌帧窗口时跳过调用。持续接触可以在无敌帧结束后再次受伤，不保留整次冲撞的命中记录。
- 双眼激光蓄能后缓慢追踪。光束由方块碰撞形状截断，命中生物造成伤害并刷新100tick的 `malum:silenced`，不叠加等级。双眼每个伤害拍共用命中记录。
- 原地抬头张口吼叫，召唤哭泣黑曜石般的紫色泪雨。每滴沿真实下降轨迹判定生物命中；方块和屋顶不阻挡。唤醒开始时也释放泪雨，持续至原有100tick唤醒结束。

具体序列：同tick头部与身体同时接触A→只调用一次伤害，扣1点；随后无敌帧窗口中尾巴接触A→不调用伤害；无敌帧结束后仍接触A→可再扣1点。激光遇墙→墙后A没有伤害或静默；移开墙→下一伤害拍命中A，造成1点伤害并刷新静默。雨滴穿过屋顶→交到A的碰撞箱→伤害1点，该滴消失。

招式间隔40tick，依次使用冲撞、激光、吼叫；追踪48格内的生存玩家，也会反击攻击者。远于28格时先寻路接近；方块不会禁止整套招式开始，激光自行截断、冲撞遵循接触拆墙、泪雨穿过方块。非战斗时保留原有巡游；沉睡、唤醒和展开阶段不发动战斗招式。冲撞速度0.8格/tick，激光最长40格，泪雨半径12格、每tick8滴、下降速度0.9格/tick、每滴最多存在30tick。

护甲20。简单、普通、困难首次生成的生命池分别为400、600、800，沿用基类的每UUID持久化账本，存档中保留生成时的血量难度。伤害使用当前世界难度：基础值×倍率，简单0.5、普通1、困难1.5，和平为0。三招分别配置 `demiurge.chargeDamage`、`laserDamage`、`rainDamage`；比例配置 `easyDamageMultiplier`、`normalDamageMultiplier`、`hardDamageMultiplier`。这些项目位于 `maledict-common.toml`，修改基础值后各难度按比例变化；原版玩家伤害不再额外缩放一遍。

三招统一按世界难度选择ChangeLib伤害方法：简单为LIGHT（`lighterDamageMethod`），普通为MEDIUM（`mediumDamageMethod(..., false)`），困难为FINAL（`finalDamageMethod(..., finalNoRemove(), false)`），均不追伤：第一条路径已有真实扣血后，不再补足护甲、减伤等削去的差额。每次进入探针前检查原版无敌帧窗口，防止把无敌帧挡下的连续接触升级成强制伤害。

Malum实体精魂数据为神圣6、邪恶7、邪术8、幽影3，主精魂为邪术。与腐枯凋灵一样通过原生精魂获取流程产出。

Blender逐tick导出的三段姿态与唤醒、蛇行共用同一模型；公共端 `DemiurgeRig` 同时驱动渲染、分段碰撞箱与双眼发射位置。战斗状态与起始时间通过实体数据同步，加载存档时终止未完成的战斗招式；唤醒的持久化时间线保持原有规则。
