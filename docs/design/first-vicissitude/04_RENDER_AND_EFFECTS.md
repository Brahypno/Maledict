# 04 — 渲染与真实投掷

## 职责

具体依赖 API、技能效果映射和验收见 [10 — 特效接入清单](10_VFX_INTEGRATION.md)。Lodestone/Malum 的复用覆盖粒子曲线、柔光、斩弧、拖尾、命运线和地面预兆，不限于震动。

Entity/Goal 管理服务端阶段和命中；Model 管理骨骼/姿势；Renderer 管理材质、视锥范围和持物 layer；emissive layer 仅画少量冷白核心/裂缝；effect layer 管命运线、星轨；独立 Projectile 管投掷轨迹与命中。禁止把飞出的镰刀藏在 Boss 模型里用 visibility 假装弹体。

建议首版效果：头核/少量环片 emissive、翼尖释放提示、短羽光轨、投掷轨迹细线、完整技能预警、转场裂光和死亡熄灭。胸口留空，深部弱光不能填成核心球。07 的胸/环场地预警属于首版。全屏滤镜、自定义 shader、新音乐当前不制作，但必须保留 08 的后续接入位置，不能永久排除。

延用已接入的 Malum/Lodestone builder 和缓存 RenderType，尽量不复制 Malum 贴图到项目。发光不等于真实动态照明。所有纯视觉代码只在客户端运行；受粒子设置和距离控制。建议每 Boss 自定义持续效果上限 120 个存活粒子、每 tick 新增最多 8 个，瞬间事件可短暂增加 40 个；基础模型和可读预警不能依赖粒子开关。

## 投掷闭环（首版基准）

- 只在二阶段、主手有武器、当前没有飞行镰刀且看见有效目标时选择。
- 距离 6–24 格优先投掷，冷却 120 tick；近战与更远距离攻击见 07。空手期间可以翼尖普通远程，不造成隐形持械近战伤害。
- 第一版直线飞出、再追踪返回，不做环形伤害路径。初速度建议 0.8 格/tick；出行最多 20 tick 或 16 格，命中方块则开始返回；总寿命最多 100 tick。
- 去程只对当前锁定目标命中一次，建议伤害取 Boss 攻击属性、使用 SCYTHE_SWEEP；不自动附加玩家 Incursus 的整套主动技能/多通道连锁。回程无伤害。这些平衡选择按用户允许的首版数值基准采用，后续可调整。
- 返回距离 Boss 手部小于 1 格则归还武器，进入 recover；不穿越世界边界追随主人。无效目标提前返回，Boss 死亡则取消并销毁 Boss 专用武器副本，不掉落。
- “投出”是 throw，没有必须透明显现的设计。使用当前难度真实 ItemStack 及其材质，保留 NBT；三种武器分别校准握持与飞行显示尺寸。

## 物品与实体所有权

持握 → 去程 → 回程 → 接住 → 持握；同一 Boss 最多一个有效投掷 token。释放成功时由服务端将主手 stack 移交给暂存/弹体，客户端只显示状态。超时按 token 回收一次，旧弹体即使重新加载也不得重复归还。保存 Boss UUID、投掷 token、stack、剩余时间；主人区块卸载时停止有效命中，加载后核对 token。

难度在飞行中改变时建议延迟换装到本次回收后；不得在手中立即生成第二把。Boss 武器不让玩家捡取。返回失败采用服务端收回并清理弹体，不让 Boss 永久空手。

本地方法体已证实 Malum throwScythe/pickupScythe 依赖玩家槽位与 ServerPlayer（见 00），不能直接调用。Boss 使用自己的投掷/接回入口，参考 Malum 创建弹体、设置 stack、发射和声音；需要时新增 Boss 专用注册弹体与 renderer，复用 item 渲染及 Malum 视觉 API。此为技术选择，无需单独设计审批。

## 视觉边界

碰撞箱和视觉包围盒分开。建议身体碰撞 1.6×4.375 格，双翼增加分段受击区域并共享 Boss 真生命；主环属于身体结构。用户已要求双翼阻挡玩家及地形，支持不同部位倍率，细则和倍率建议见 08。视锥裁剪包含最大翼展与主环，飞行镰刀独立裁剪；不能仅扩大 renderer.scale 留下玩家大小的隐形命中箱。

第三人称前后左右、实体旋转、跨阶段中间帧、低粒子设置、不同难度物品均检查。线程/服务端加载验证必须覆盖新增 renderer 与 effect 不被 common 静态初始化引用。
