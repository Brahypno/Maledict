2026-09-13 补充：用户要求继续利用 Lodestone/Malum 其他能力改善特效；已完成本地 API 核对与逐技能接入表（10）。这属于已有视觉范围细化，无需增加新的工具选择审批，不改变 D6 尚未确定的返还交互。

D6 现已关闭：采用自动返还，并在无法交付时发放 `maledict:curio_return_token` 凭证兜底。
自动返还负责把饰品送回原槽／其他合法空 Curio 槽／背包；任何一步失败都不删除记录、不丢地上，
凭证只在全部交付完成时消耗，因此满背包不会吞物品。实现与未验证项见 [11](11_ACCEPTANCE_RECORD.md)。
