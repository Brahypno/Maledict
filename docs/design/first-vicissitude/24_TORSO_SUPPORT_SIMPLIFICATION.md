# 躯干连接审查与截面简化

正面看不到的连接不能直接视为永久隐藏。左右胸壳会在动作中张开，死亡露核时左右胸壳与背甲也有相对运动；因此没有根据单帧遮挡删除整根连接。

## 检查结果

对修改前躯干候选的 395 个多边形面、20 块实体甲片进行同关节覆盖检查。甲片按凹轮廓拆为三棱柱体积，用体积并集覆盖完整候选面，而不是仅测试顶点或正面截图。未找到满足该范围判据的完整可删面；这不证明不存在局部交叠或其他可删结构。

完整方块或低截面支撑配合独立甲片，能从建模阶段减少几何复杂度。本轮采用这一方法简化连接，没有把“换截面”记作“删除隐藏面”。

## 实际修改

| 两侧合计 | 原三角面 | 新三角面 |
| --- | ---: | ---: |
| 胸廓承重弧 | 88 | 56 |
| 锁骨连接弧 | 64 | 40 |
| 肩胛至翼根连接 | 64 | 40 |
| 合计 | 216 | 136 |

六个连接网格由六边截面改为四边截面，保留原有中心线、关节和纹理语义。截面轮廓有所变化，因此输出正背面与无灯光近图核对。没有修改外覆甲片、环绕肋骨、双臂、翼片和环本体。

总面数 3,584 → 3,504；二阶段 3,284 → 3,204；对象仍为 185，关节仍为 65，贴图仍为 256×256。图集随减少的侧面区域重新打包，占用 48,320 像素。Blender、Blockbench、运行时网格与贴图同步更新。

逐面 UV、镜像复用、导出一致性、胸洞、胸环及姿态范围检查用于验证本轮修改；离线预览不能代替游戏内视觉验收。此次只是连接截面的局部简化，不声称已经消除全部内部面或达到最终几何预算。
