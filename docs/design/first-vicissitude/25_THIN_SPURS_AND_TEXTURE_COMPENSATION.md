# 短分叉与贴图补偿

## 最新一轮：主翼纹理细化

按用户要求，对照目录仅保留一套滚动的 before/after：上一轮 after 已成为本轮 before，本轮结果覆盖 after，仍为七组视角，不新增历史图片集合。下文短分叉数字保留为历史记录，图集与 `geometry-comparison.json` 现对应本轮。

本轮重新检查本地参考的翼面结构与纹理分工，重点采用沿结构安排亮面、暗槽和材质交界的方法。四类主翼分别编排自己的骨脊宽度变化、斜向细脊与裂纹路径，替换贯穿全长的等宽色带和孤立方块裂痕。翼根保留接触暗部，骨色嵌脊逐渐变细，紫色宽面承接侧影；背面和内侧保留各自的明暗映射，端面独立绘制。左右对应部位仍复用。图稿源新增 `art/first-vicissitude/tools/wing_surfaces.py`，由原生成器调用，不复制外部资源。

这轮选择保留主翼现有三角截面的厚度，不进一步薄片化。185 个部件导出几何与 UV 全部和 before 一致，总三角面仍为 3,344，二阶段 3,044。图集仍为 256×256 / 263 区域 / 48,320 占用像素；改进来自区域内重新设计的像素分布，而非增加面数、扩大图集或重复小格。

同条件渲染已更新，整体视角下可以辨认宽窄骨脊与顺势暗槽；近图可见裂纹和浅脊，背面较正面暗。法线、UV、镜像复用、导出一致性、胸洞与环座检查通过。几何和动作未变，未重复宣称新的性能收益；游戏内观感尚未验证。

## 上一轮：短分叉减面

2026-09-23。本轮处理左右共十个短分叉。查阅本地参考源码，确认大型翼面采用零厚度片、左右镜像复用 UV 的结构方法后，制作本项目自己的混合结构：第一段仍为封闭实体接头，远端保留原正面曲面带，通过已有的不剔除背面渲染显示两侧。没有复制外部代码或资源。

原正面轮廓顶点全部保留，保留顶点没有位移；其余 175 个部件导出数据一致。删除的是远端第三条隆起骨脊与相应背侧面，主翼和承重连接保持厚度。

贴图仍为 256×256、263 区域。钩部使用 28×8、其他短分叉使用 24×6 正面区域，沿长度分别安排根部接触暗部、骨脊亮面、紫色侧影、尖端收暗和裂痕。UV 纵向按曲线累计长度分配，左右复用，实体根部仍有独立背侧面与封口。不靠重复小格增加所谓精度。

近图中伸展轮廓与根部连接保留，骨脊亮面使短分叉更易读。实际损失：薄片两侧共用纹理，背面比旧版更亮，独立背脊明暗消失；严格沿片面方向观察时远端失去厚度，纹理不能补回这项几何损失。因此没有将此方法扩展到大块主翼。没有宣称达到未经定义的“80% 细节保留率”。

检查通过：法线、UV、44 对镜像复用、游戏与 Blender UV 一致、胸洞 12/12 射线贯通、环座 32/32 射线贯通；Java 验证 115,968 次翼顶点/动作/阶段/朝向/收翼组合、3,060 次翼姿态和 15,824 次胸环同心顶点检查。动作检查为数值验证，游戏内运动观感和帧率尚未验证。

生成来源为 `build_blender.py`、`surface_sample.py`，对照渲染为 `review_spurs.py`。修改前基线暂存在忽略目录 `build/spur-review`，`compare_spurs.py` 依赖其中旧网格。此基线与图集目录的 `geometry-comparison.json` 随最新一轮滚动替换，历史数量以本文件表格为准。
