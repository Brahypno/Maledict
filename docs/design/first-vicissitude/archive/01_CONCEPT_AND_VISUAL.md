# 01 — 概念与视觉

来源：[原始概念全文](source/01_CONCEPT_AND_VISUAL.md)。本页保留核心主题，尺寸采用可调首版基准，美术交付和自主权已确认。

## 主题契约

神圣遗骸制造的失败实验体，被未完成的命运重新唤醒。情绪是冷静、无奈、不得已。不是神本身，也不是恶魔或传统骷髅死神。

必须呈现：非人头部、无腿、头后断环、真实中空胸腔、骨羽混合双翼、三节中央残躯及周围碎片。第一阶段像高位圣像，第二阶段像前倾的执行者。死亡时揭示拼接结构，最后熄灭而非爆炸。

2026-09-13 美术反馈澄清：头部可参考末地水晶的分层内核与外壳，保留尖锐星芒和多面开裂，
不是完整立方体。胸甲也不采用矩形箱体；胸腔空洞需收小，周围必须有足够的胸肩、侧壁与腹部体积。
手掌应与前臂、腕部协调并保持简化；贴图需明确呈现冷骨白与黑紫材质层次，避免灰模观感。

## 建议定标

| 项目 | 建议规格 | 验收 |
| --- | --- | --- |
| 主体 | 70 模型单位 = 4.375 格；不含环、翼尖和特效 | 旁置 Warden 对比；不重复 renderer 放大 |
| 翼展 | 常态 116 单位 = 7.25 格；最大 128 单位 = 8 格 | 正、侧、背及远景轮廓 |
| 头核 | 约 6×7×6 单位，被分离外壳遮盖大半 | 无眼鼻口；死亡时才完整展示 |
| 主环 | 4 个不等长断片，缺口永久存在 | 不靠透明贴图伪装断裂 |
| 胸部 | 至少前后部分角度能直接看穿；左右及底部残环 | 不用发光球填满空洞 |
| 双翼 | 左翼羽片较完整、右翼骨架较裸露，整体视觉重量平衡 | 关掉粒子仍识别骨→羽→破损 |
| 下身 | 3 节脊柱/祭衣残躯，左右骨片与祭衣片 | 无腿形和完整幽灵尾巴 |

所有模型单位按 16 单位/格转换；原稿 px 在此指几何单位，不等同 256×256 纹理像素。

用户第二轮说明：主环和躯干属于同一身体结构，独立动画关节不表示独立实体；双翼需要受击判定，细则见 08。两张原型图是可选参考，见 [参考说明](references/README.md)：可借鉴横向大翼、纤细中轴、悬浮和骨羽分层，不照搬白亮主色、面部结构、腿形或原作身份；文档主题优先，不要求 100% 复刻。

建议色板：深黑紫 `#19151F`、灰紫 `#49404F`、冷骨白 `#B8B8C4`、冷白 `#E6EDF5`、暗紫能量 `#51436D`。色值可在主题内微调，不用高饱和紫、红眼、肉翼、恶魔角或大面积金色。暗处靠材质层次保持结构，不做全身发光描边。
