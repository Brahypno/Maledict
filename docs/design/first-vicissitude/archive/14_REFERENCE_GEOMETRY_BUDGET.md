# 14 — 无常几何预算与历史

2026-09-20 用户补充：面数适当减少，到知名大型 Boss 模组最终 Boss 的平均水平。

## 预算口径

几何数量以项目实际导出的三角面数为准。盒体声明数乘以 12 只能粗估上限；零厚度面、外置武器、附加渲染层与可见性均会影响比较结果。早期调查的有限样本估算均值为 1,110，仅作为历史预算依据，不代表行业平均，也不能代替形体质量判断。

当前版本见目录中的最新修订；下方为首次减面阶段的记录。

## 无常的实际交付

**历史版本说明**：以下 1,488 面是首次减面版。用户随后反馈粗糙，最新翼部按 [15](15_WING_STRUCTURE_AND_FEATHERS.md) 重做为 1,792 面，旧 1,500 制作上限由该轮质量修订替代；本页保留预算历史。

主体实际导出 **1,488 个三角面、108 个网格部件、65 个关节/锚点**。采用 1,200–1,500 三角面的制作预算，处于参考样本同一数量级，靠近上沿；比早期样本估算均值高约 34%，为双翼的前后层次和真实胸洞保留余量，不能写成“等于行业平均”。

原主体为 23,244 三角面，本轮减少约 93.6%。网格不包含运行时绑定的武器和粒子；发光层重复提交也不计入主体几何数量。因此这里只承诺模型预算，不把减面百分比当成帧率提升。

保留几何：前后贯通胸洞、可独立分离的头壳、四段断环、三节残躯、主翼骨、关节羽组和右翼缺损。删除几何：重复背层、逐羽细骨条、细小缝合钉、环上的高密度刻度和重复装饰弧。羽轴、磨损与拼接感交由像素图案表达。

后续新增细节应优先替换现有预算内的形体和 UV，避免再次依靠堆叠网格提高精度。模型数量由 `preview/blender/mesh-report.json` 的实际导出结果核对。
