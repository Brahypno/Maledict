# 胸环与背环的表面贴图替代

本轮把银轨、凹槽、卡扣和横向刻印移入贴图，保留实体环本体与断口。环中心、曲率采样、关节和主体截面不变。

## 几何与图稿

- 删除 30 个装饰网格：固定座唇边、胸环银轨与卡扣、背环银轨、内侧凹槽与横向封印条。
- 保留 11 段实体：4 段固定环座、3 段转动胸环、4 段背环。两种运动层级仍各自绑定，固定环座不会跟随胸环旋转。
- 新增 `art/first-vicissitude/tools/ring_surfaces.py` 作为环的原创像素图稿源。明暗剖面表达嵌入银轨、接触暗线及边缘高光，明确指定卡扣和断纹位置；没有增加实体刻纹。
- 每类环分别展开正面、背面、内侧、外侧及两个断面。胸环和环座正背面各 40×8、侧面各 40×4、断面各 8×4；背环正背面各 64×12、侧面各 64×6、断面各 12×6。同类弧段复用图稿。
- 背面使用凹刻标记，侧壁使用厚度明暗，断口使用暗芯和裸露金属边；不把正面银轨重复投影到所有面。长度 UV 沿实际截面中心累计距离展开。
- 图集仍为 256×256。逐表面区域预留 144 行，剩余 112 行容纳旧稿；总占用 48,896 像素。头部、羽片和部分残片仍待后续重绘。

## 验证与交付

Blender、Blockbench、运行时 JSON、基础贴图和自发光层已同步。逐面 UV 检查确认 11 段环均有六类独立表面区域，且旧装饰几何不再存在。胸洞射线、同心半径、导出 UV 一致性、法线及镜像复用通过。

独立姿态检查通过：15,824 次胸环顶点同心检查、3,060 次翼姿态检查、123,648 次翼顶点与动作/阶段/朝向/折翼范围检查。预览增加 `ring_chest_detail.png`、`ring_halo_detail.png`、`ring_halo_back.png` 和 `ring_turn_detail.png`；旋转近图为离线 70°姿态检查，不冒充游戏内连续动画测试。

单独重渲染环近图：检查脚本使用 `-- --rings-only`；完整本轮近图仍可使用 `-- --sample-only`。
