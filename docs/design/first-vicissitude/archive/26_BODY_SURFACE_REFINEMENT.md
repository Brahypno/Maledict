# 肩臂、胸背和腹部表面修订

本轮延续已认可的主翼纹理。检查本地参考的胸甲、手臂、拳头结构与纹理分工后，以宽厚实体搭配表面明暗的方式重画本项目图稿，没有复制外部代码或资源。

## 本轮变化

- 肩冠、上臂和前臂采用连续宽亮面，暗部集中在接头和下缘；避免在每个小面重复圆润的渐变。
- 胸甲保留大块受光面，下沿留压暗；背甲增加靠内侧的骨脊与凹槽，外壳和骨质继续使用不同色组。
- 拳头保留三枚实体指节与拇指，指节正面连贯，折返处和指缝压暗。掌面逐步转入拇指连接的暗部。
- 用户查看中间结果后要求继续细化胸环下方：将腹部大十字亮块改为窄中央骨脊、成对横向骨片、分段接触缝，重画侧腹、胸骨和肋条；背部中央改为凹槽，两旁留亮脊。

图稿源为 `art/first-vicissitude/tools/body_surfaces.py`，通过既有 `surface_sample.py` 写入各表面区域。12 类角色分别设计，正背、内外侧、截面按结构分工，左右对应部位仍复用。贴图尺寸仍为 256×256，没有增加贴图层。

## 几何选择与验证

肘轴承担关节连接，指节和拇指决定拳头轮廓，胸前骨脊仍会在斜视中提供突出轮廓，本轮保留这些几何。185 部件的导出几何和 UV 与 before 完全一致，3,344 三角面、二阶段 3,044 面、65 关节不变。这轮是纹理层次修订，不作为进一步减面或实机性能提升。

UV、44 对镜像复用、导出一致性、法线、胸洞 12 条射线与环座 32 条射线检查通过。游戏内观感仍未验证。
