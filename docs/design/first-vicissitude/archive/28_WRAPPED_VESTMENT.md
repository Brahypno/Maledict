# 环绕下腹的残破祭衣

用户否定了 27 中两枚狭窄挂片的视觉结果。本轮重新检查本地三个大型首领参考的布摆与披风结构：宽布面从身体承接，上下薄片分段，贴图负责褶皱与破口。只采用结构方法，未复制任何代码或资源。

## 本项目的处理

沿用 01 的三节残躯、两侧祭衣残片和无腿方向。左右两幅由下腹两侧向后包绕，中间保持敞开，保留脊柱和胸洞可读性；不做完整披风或幽灵尾巴。原先孤立窄片改为宽幅、下部外展的残衣，左右长度不同。

每幅横向两个折面、纵向三段，共 12 三角面。褶皱主要画在纹理上，宽面转折才使用几何。既有 `cloth_fragment` 关节继续驱动整幅，不新增上下摆关节或布料物理；离线图不代表已验证战斗中所有姿态的穿插。

两幅共用原创 16×32 区域，代替上一轮 16×16。沿长度画出收束褶皱、根部接触暗部、断续缝线和磨损；参差底边、侧边豁口和局部撕裂使用 alpha cutout。去掉旧版矩形边框式挂饰感。保留现有双面渲染，没有叠加透明渲染层。整个图集仍为 256×256；占用像素 48,320 → 48,576。
