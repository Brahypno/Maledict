## 什么时候来看这里

只在需要回答「某一轮到底改了什么、当时为什么这么定」的时候。
正典里已经写了结论；这里留着的是过程和被放弃的方案。

## 哪些内容已经被推翻（不要照抄）

- **面数**：1,488 / 1,792 / 2,188 / 3,312 / 3,504 / 3,572 / 3,584 / 4,416 / 5,246 / 5,552 都是过程值。
  当前是 185 网格 / 3,344 三角面 / 二阶段 3,044 面。
- **一阶段时长**：180/140/100/75 秒的方案已废止，当前是 1800/1400/1000/750 tick。
- **一阶段节奏**：基础槽 40 tick、技能冷却 160/200/240 都是旧值，当前是 30 tick 与 70/90/80。
- **交战半径**：19 写的 12 格已改为 96 格。
- **每击上限比例**：21 写的 SIMPLE 20% 已改为 10%。
- **近战判定**：07 的「半径 + 扇形角」已被刀刃线段扫掠取代（横斩 100°、竖劈 5×1.5、
  重击 120° 这三个几何描述都只在历史上成立）。
- **压血喘息**：18 规定的「压血弹落地后 30 tick 不再释放」已在第十六轮整条取消。
- **XP 奖励**：12/18 写的 100 已改为 1000。
- **适应效果的措辞**：21 写成「顶掉最早记下的一条」（FIFO），实现是「最新在前、命中即前移、
  顶掉最久未命中」（LRU）。两者在重复命中同一 message 时结果不同，以实现为准。
- **部位倍率的语义**：08 把它写成「进入父 hurt 前的原始伤害倍率」，
  实现是乘在单次命中上限上——两处都乘会把同一个优势算两遍。
- **16×16 单元模板式图集**（20 的方案）已被用户否决。
- **祭衣窄挂片**（27 的方案）已被用户否决，28 重做为宽幅包绕残衣。
