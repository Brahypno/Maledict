# 倒吊人的愚见 / hangman·sfool

物品 ID：`maledict:hangman_fool`，仅使用 `delusion`（视界）槽位。暂不添加配方。
即使通过其他模组或指令强行装进其他饰品槽位，也不提供属性、战斗能力或负面限制。

## 已确认的阶段模型

物品无阶段 NBT 时为 0 阶段，自带两项属性。共五个状态：0 → 1 → 2 → 3 → 4。
升级依次在 `HangmanFoolStages` 下添加布尔标记 `stage_1`、`stage_2`、`stage_3`、`stage_4`，
保留名称、附魔及其他 NBT。必须连续具有前阶段标记才会解锁后阶段：仅有 `stage_2` 的物品仍为 0 阶段。

- 0 阶段：攻击力 ×0.5，魔法熟练度 ×1.5；均为 `MULTIPLY_TOTAL`，不需要额外 NBT。
- 1 阶段：继承 0 阶段。自己拥有的弹射物撞到方块时，取消原撞击，保存弹射物并留下陷阱。
  首个接触的非佩戴者、非友方生物消耗法阵，触发原弹射物完整的 `onHit(EntityHitResult)` 分支，包含伤害。
- 2 阶段：继承前两阶段。弹射物即将命中佩戴者时，以
  `min(1, 0.25 + 1 - health / maxHealth)` 判定反弹。
  满血 25%，半血 75%，剩四分之一生命时 100%。成功后取消本次命中，速度向量整体取反，
  保留速度大小，同时立即重设当前和上一帧的朝向。归属变为佩戴者，反弹弹射物落地仍可留下法阵。
  火球的加速度也取反。此阶段开始无法举盾、格挡或触发不死图腾。
- 3、4 阶段：仅保留阶段判定，尚无新增能力、配方或独立美术；不放入创造列表。

示例：1 阶段射出火矢附魔箭 → 撞墙成为法阵（此时不触发撞墙分支）→ 生物接触 →
结算原箭伤害及火矢 → 法阵消失。2 阶段反弹成功 → 此次不受弹射物命中 →
箭头随反向速度转向 → 撞墙 → 同样的单次陷阱流程。

## 实现与暂定参数

命中事件使用 `HIGHEST`，优先于普通优先级的追忆穿墙效果。取消命中事件后，Forge 自行结束
穿透箭的本次碰撞循环，再按反向速度继续本 tick 的原版移动、阻力和重力，不改变穿透等级。

法阵暂定 600 tick、接触距离 1 格；反弹基础概率、寿命和接触距离位于
`hangmanFool` 配置。陷阱只保存原弹射物 NBT，不持续 tick 原弹射物。
只沿用弹射物自身的 NBT，不补存原版未持久化的附加字段。恢复原速度，避开 `Entity.load` 对大速度分量的截断。
触发时重新经过 Forge 命中事件，再调用原弹射物的完整命中方法。

客户端使用 Malum 法杖施法的 `hexagon` 纹理和 Lodestone 加法混合，固定绘制两个旋转面片，
不持续产生粒子，不添加常驻后处理。每个法阵仅做一次局部生物查询，最长存在 30 秒。
反弹时发送一次客户端通知，立即调整速度方向、当前及上一帧朝向、归属和火球加速度。
之后沿用原版运动同步，不补修原版的高速运动包截断，不做持续校正。
使用 Forge 命中事件，不修改原版箭矢 tick 或实体追踪方法。

0、1、2 阶段分别使用紫水晶碎片、海晶碎片、回响碎片作为贴图占位。
按住 Shift 时额外显示当前阶段对应的一条风味文本，分别使用
`tooltip.maledict.hangman_fool.flavor.0` 至 `.4` 五个键，中英文暂为空；
空内容不占提示行，也不显示 Shift 操作提示。

手动测试 2 阶段可用：

```mcfunction
/give @s maledict:hangman_fool{HangmanFoolStages:{stage_1:1b,stage_2:1b}}
```

`HangmanFoolTest` 固定阶段序列、属性与禁用行为、反弹速度和箭头方向、穿透旧射线终止、
法阵单次触发和存读档，并检查附魔箭、药水箭、光灵箭、药水、法杖、精魂箭、火球、烟花和三叉戟的原有命中分支。
