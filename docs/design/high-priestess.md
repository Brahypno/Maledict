# 女祭司之灵相

能力逐阶段累计：0 阶段提供 0.5 超越预兆；1 阶段生命显影；2 阶段未至之伤；3 阶段灵魂离位。

## 生命显影与性能

16 格内的存活生物显示原版发光轮廓，包括隔墙和隐身目标，仅佩戴者可见。残影实体不参与。
客户端每 tick 查询一次自身视界槽，缓存是否启用；原版渲染已经访问到候选实体时，再做存活、同世界与平方距离判断。
不查询附近实体、不排序或维护目标列表、不做视线射线检测、不逐帧读取 Curios、不发网络包，也不添加发光药效或修改实体标志。
成本为每 tick 一次槽位查询，以及原版已访问实体的 O(1) 判定；复用原版轮廓缓冲与后处理。

### 客户端 mixin 所需的具体能力

`LevelRenderer` 在调用实体渲染器及 `RenderLivingEvent.Pre` 之前，已经通过
`Minecraft#shouldEntityAppearGlowing` 决定是否传入 `OutlineBufferSource` 和运行轮廓后处理。
`RenderLivingEvent` 没有替换该缓冲或开启外层轮廓处理的接口。
Forge 的 `Entity#hasCustomOutlineRendering` 是实体类型自己的覆盖点，不能为其他模组生物和玩家添加当前观察者的规则。
因此客户端只在 `Minecraft#shouldEntityAppearGlowing` 查询实体发光状态的调用点补充生命显影判定，保留原版已为 true 的结果。
使用布尔值重定向，不在每次判定时构造 cancellable 回调对象。
这是为了复用原版路径，避免再绘制附近所有实体模型及额外全屏后处理。

## 灵魂离位

法术直接命中本体后，在其当前位置留下 60 tick 残影。每个目标只有一个；再次直接命中刷新原位与期限。
残影停在原位，法术命中它时将原伤害来源与原始伤害量交给本体的普通 hurt 流程，防御、无敌帧与伤害归属照常计算。
转交期间不创建或刷新残影；实体在本体死亡、离开所在世界或期限到达时清除。残影不保存到存档。

确认序列：t=0 法术击中 A 并留下残影 P；A 移动至 Q；t=20 命中 P 只伤及 A，P 的期限仍为 t=60；
t=40 直接击中 A，唯一残影移动至 Q，期限刷新至 t=100；t=100 清除。
