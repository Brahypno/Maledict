# Boss 的血量模型

第一化身、巨匠造物主、腐枯凋灵三个 Boss 的血量都不是一个普通的实体字段：它有一个权威池、一套单次命中上限、
一组分阶穿透规则和多种回血来源。具体数值见 [boss-combat-numbers.md](boss-combat-numbers.md)。

## 权威池

- 世界的 `SavedData` 账本（`VicissitudeVitalityLedger`）是**唯一权威**。
- 实体上 `getHealth()` 只是视图；客户端优先使用 ChangeLib 提交的快照，快照到达之前才用同步的
  `DISPLAY_VITALITY` 显示。
- 重载、跨区块、重开服务器都会保留伤口，不会回满。

## 单次命中上限与同 tick 合并

- 每次命中最多扣 `真生命上限 × 比例 × 部位权重`。第一化身按难度 5%/3%/1%/1%（头 ×1.25、翼根 ×0.75、
  外翼 ×0.5），巨匠 3%，腐枯凋灵 5%。
- 同一 tick 的多个通道（同一挥砍的多次命中、奥术/霜冻、事件里追加的伤害）视为**一批**：每通道各自结算，
  但只扣「超过本批已有最大扣血量」的差额，**不相加**。所以一刀多通道不会因为通道多而突破上限。
- 两道门串联：原版 `invulnerableTime` 与 Boss 自己的命中门（第一化身/巨匠 20 tick）都要放行。

## 分阶穿透

伤害按来源分阶：D3 存储写入 / D4 一致性写入 / D5 恢复来源。Boss 自身的防御等级是：第一化身 **D4**、
巨匠 **D5**、腐枯凋灵 **D3**。

- 低阶武器（LIGHT）会被单次上限卡住；MEDIUM / FINAL 阶更高，可以按额度穿透上限，把超出部分落下来
  （能穿透多少取决于 Boss 的防御等级）。
- 补偿（compensation）不会提升攻击阶段，也不会重开额度；只有真正升阶到 D5 那一步才可能结算剩余伤害。
- 这一点是刻意的：普通攻击打不出上限之外的伤害，高阶武器才行。

## `setHealth` 与击杀

- 外部 `setHealth`、存储写入都是**请求**，会重新走 Boss 的 `hurt` 规则（免疫、适应、冷却、单次上限）。
  直接 `setHealth(0)` 或直接调 `die()` 不会真的杀死 Boss。
- 强制击杀有计数：100 tick 窗口内第 3 次强制归零才进入真正的死亡流程；`kill()` 与 `remove(KILLED)` 走同一条路。
- 死亡流程本身也归 `CombatProtection.allowDeath` 管，不放行时死亡被吞掉。

## 回血

| 来源 | 规则 |
| --- | --- |
| 脱战回血（第一化身 / 巨匠） | 无存活目标、无存活攻击者、且最近 100 tick 没有结算过伤害时，每 tick 回复最大生命池的 **5%**（第一化身 25 / 37.5 / 50 / 75；巨匠 20 / 30 / 40）。转场（阶段一→二，60 tick）与召唤仪式期间不回。 |
| 脱战回血（腐枯凋灵） | 同一套判定，每 tick **20**。重聚期间 `heal` 直接拒绝。 |
| 自然回血（腐枯凋灵） | 每 20 tick 回 1 HP，最终阶段关闭。 |
| 增殖（腐枯凋灵） | 命中「已经有凋零」的有效目标回 3 HP，整只实体共用 40 tick 冷却。 |
| 击杀回血（腐枯凋灵） | 凋灵之首直接击杀目标回 5 HP。 |
| 出生无敌（腐枯凋灵） | 220 tick 内每 10 tick 回 10 HP。 |
| 重聚（腐枯凋灵） | 首次致死 → 1 HP + 60 tick 重聚 → 80 HP + 强度 7 爆炸；只发生一次，最终阶段不再重聚。 |

> 「最近 100 tick 没有结算过伤害」这条记忆是必要的：被人在仇恨范围外远程点射时 Boss 选不到目标，
> 只看目标会让它一边挨打一边回血。100 tick 与原版 `lastHurtByMob` 的记忆长度一致，所以体感是
> 「停火 5 秒后开始回血，1 秒回满」。
