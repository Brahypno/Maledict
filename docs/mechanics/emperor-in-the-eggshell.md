# 蛋壳中的皇帝

佩戴时，方块和实体交互距离各降低 50%。防护有两道上限，分别由 `emperorInTheEggshell.guardPercentage`
和 `emperorInTheEggshell.windowTicks` 控制。

- 默认单次最多扣除最大生命的 50%。上限随当前最大生命变化。设为 0 时只停用这道上限。
- 一次有效扣血开启默认 40 tick 的窗口。窗口内经过 `t` tick 的命中最多扣除原本会损失生命的 `t / windowTicks`，
  同时仍受单次上限约束。窗口内的命中不会延长窗口。原版无敌帧先于这个窗口结算。

## 受击反馈

ChangeLib 的结算报告确认蛋壳防护层介入时，客户端才播放反馈。力度按挡下的比例计算，也就是
`1 − 实际损失 / 原始伤害`。挡下的比例越高，局部亮痕与光流越亮、越长。挡下 100% 时达到最强。

第三人称和旁观者能看到三片接近实体质感的卵形护壳，从头顶延伸到脚边，片间留有空隙。护壳向内靠拢并旋扣，
朝向伤害来源的一侧短暂亮起，两道细光沿壳面散开后收窄熄灭。第一人称在屏幕两侧显示带暗缘和暖骨白内壁的
弧形壳面。两片宽壳的暗面贴到屏幕左右边界，骨白弧面与旧金内沿向内收拢，屏幕中央至少 65% 的宽度留空。
第一人称的亮痕按伤害来源相对镜头的方向定位，前方来袭偏上、后方来袭偏下。来源不明时，两侧亮度接近。
完整演出时左壳缘最多出现 4 枚浮尘，右侧最多 3 枚，每枚沿壳缘漂移约 5–8 tick。局部亮痕同时带出
最多 5 枚受击侧碎光，来源不明时左右各最多 2 枚，约 2–4 tick 内熄灭。较强的防护还会短暂点亮内壁上的纹路。

完整动画最多持续 11 tick，壳片约在第 4 tick 完成扣合。每名佩戴者每 16 tick 最多播放一次完整动画。
期间的新报告最多每 3 tick 刷新一次持续不超过 5 tick 的局部壳面及高光，碎光贴在加亮的那段壳面上。
壳缘浮尘随完整演出播放，局部反馈刷新时沿用原来的浮尘进度。切换视角沿用同一段动画。
