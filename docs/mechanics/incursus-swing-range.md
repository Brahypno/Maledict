# 神侵恶刃的近战范围

一次近战挥砍只有**一个**范围数字：

**半径 = `entity_reach` + 0.5 + 横扫之刃等级 × 0.25，封顶 6 格。**

它同时决定「打不打得到」和「腰环画多大」，两边不会各说各话。原版 `entity_reach` 是 3.0，
所以裸装一刀 3.5 格、横扫之刃 III 是 4.25 格；被模组堆高时最多算到 6 格。

## 判中条件

- **球心在挥砍者的腰上**（脚底 + 半个身高）。改造前是「脚底再朝准星前移 0.4 格」，所以与改造前相比
  正面少 0.4 格、背面多 0.4 格：范围从一个偏前的球变成以自己为心的一整圈，与 360° 的腰环对得上。
- 目标按**碰撞箱最近点**比距离：最近点距离 ≤ 半径就命中。站在台阶或柱子上的怪（脚底在圈外、
  身子在圈内）、五格宽的巨型多部位 Boss 都按可见体型判。旧判法拿「脚底点 + 半个箱宽」凑，
  这些情况会漏打，而看着明明贴着。
- 视线（`hasLineOfSight`）、`canHarmPlayer`、`isAttackable`、`skipAttackInteraction`、
  同 tick 只挥一次的记录等原版过滤照旧。
- 多部位 Boss 的目标列表仍会收敛到活体根实体：一次挥砍只开一次主探测、只派发一轮霜冻/奥术。

## 视觉

- 八瓣腰环的花瓣中心**末帧圆就是伤害球的赤道**：半径 3.5 格，环就画到 3.5 格。
- 花仍从花心向外绽开（起手约 `0.117R`，12 tick 收尾到 `R`）。每瓣的漂移倍率只决定中途快慢，
  末帧八瓣中心严格同在一个圆上；花瓣大小仍按每瓣 `0.8–1.2` 倍各不相同。
- 刀痕四边形半边 = `petalSize × 半径 / 4.27`（4.27 是这套贴图当初标定尺寸时的环半径），
  范围变大时刀光跟着变长，六格的环不会碎成八道孤立的刀光。
- 蓄力只影响伤害数值，**不再影响大小与远近**：轻点与满蓄力画出来一样大、也一样远。
  改造前按 `0.3 + 0.7 × 蓄力` 缩环，满蓄力画到 4.27 格、轻点只有 1.88 格，与实际范围两头都不对。

## 极端数值

| 情况 | 处理 |
| --- | --- |
| `entity_reach` 被模组堆到几十上百格 | 半径封顶 6 格：服务端搜索箱与客户端四边形都有界 |
| `entity_reach` 是 NaN / Infinity（属性被别的模组写坏） | 半径 0：打不中，也不画环 |
| 半径算出来 ≤ 0（负数 reach） | 同上，0 |
| 客户端收到坏包（非有限、超上限的半径） | 过同一道闸再画，坏值不会变成铺满屏幕的四边形 |

客户端配置里与尺寸有关的三项只改「怎么画」，不改「打多远」：

- `incursusRift.radialSpeed` / `incursusRift.lifetimeTicks` 只决定环**开多快**。把速度调成 0
  时环不会缩进花心，而是从头到尾贴在伤害边界上。
- `incursusRift.petalSize` 是基准半边（按 4.27 格的半径标定），实际半边按本次半径等比缩放。
