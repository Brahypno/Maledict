# 神侵恶刃的近战范围

一次近战挥砍只有**一个**范围数字：

**半径 = `entity_reach` + 0.5 + 横扫之刃等级 × 0.25，封顶 6 格。**

它同时决定「打不打得到」和「腰环画多大」，两边不会各说各话。原版 `entity_reach` 是 3.0，
所以裸装一刀 3.5 格、横扫之刃 III 是 4.25 格；被模组堆高时最多算到 6 格。
（1.21 这条属性是原版的 `Attributes.ENTITY_INTERACTION_RANGE`；NeoForge 早已删掉自己的 reach 属性。）

## 判中条件

- **球心在挥砍者的腰上**（脚底 + 半个身高）。1.20.1 改造前是「脚底再朝准星前移 0.4 格」，所以与改造前相比
  正面少 0.4 格、背面多 0.4 格：范围从一个偏前的球变成以自己为心的一整圈，与 360° 的腰环对得上。
- 目标按**碰撞箱最近点**比距离：最近点距离 ≤ 半径就命中。站在台阶或柱子上的怪（脚底在圈外、
  身子在圈内）、五格宽的巨型多部位 Boss 都按可见体型判。旧判法拿「脚底点 + 半个箱宽」凑，
  这些情况会漏打，而看着明明贴着。
- 视线（`hasLineOfSight`）、`canHarmPlayer`、`isAttackable`、`skipAttackInteraction`、
  同 tick 只挥一次的记录等原版过滤照旧。
- 多部位 Boss 的目标列表会收敛到活体根实体（`IncursusBladeAttack#uniqueLivingTargets`，走 ChangeLib 的
  `LivingTargetHelper#getLivingTarget`）：一次挥砍只开一次主探测、只派发一轮霜冻/奥术，认主连带也只连带一次。

## 视觉

- 八瓣腰环的花瓣中心**末帧圆就是伤害球的赤道**：半径 3.5 格，环就画到 3.5 格。
- 花仍从花心向外绽开（起手约 `0.117R`，12 tick 收尾到 `R`）。每瓣的漂移倍率只决定中途快慢，
  末帧八瓣中心严格同在一个圆上；花瓣大小仍按每瓣 `0.8–1.2` 倍各不相同。
- 刀痕四边形半边 = `petalSize × 半径 / 4.27`（4.27 是这套贴图当初标定尺寸时的环半径），
  范围变大时刀光跟着变长，六格的环不会碎成八道孤立的刀光。
- **环带的厚薄由 `petalSize` 决定，默认 2.5。** Malum 的刀痕贴图里有效笔画只占 5%，中段厚度约是
  四边形的四分之一：旧的 3.75 在八瓣散开时看不出问题，但八瓣对齐到同一个圆之后，单道 1.5 格厚的
  中段会连成一整圈，环带厚度达到半径的 43%，读成一圈实心。2.5 把中段压到约 1 格、仍能围成闭环；
  低于 2.0 会碎成八段虚线。
- **蓄力只改薄厚与收尾，不改大小与远近**：轻点与满蓄力画出来一样大、也一样远。
  改造前按 `0.3 + 0.7 × 蓄力` 缩环，满蓄力画到 4.27 格、轻点只有 1.88 格，与实际范围两头都不对。

蓄力的观感有两条曲线（都在 `IncursusRiftGeometry`，蓄力值由服务端随报文下发）：

| | 轻点（蓄力 0） | 满蓄力（1.0） | 说明 |
| --- | --- | --- | --- |
| 不透明度 | 30% | 100% | 八片花瓣同平面重叠，实际观感是 `1-(1-a)ⁿ`，所以读起来是「薄」而不是「淡」 |
| 寿命 | 默认 12 tick → 7 tick | 12 tick | 开合按寿命归一化，缩短寿命只让花收得更快，**末帧半径不变** |

## 极端数值

| 情况 | 处理 |
| --- | --- |
| `entity_reach` 被模组堆到几十上百格 | 半径封顶 6 格：服务端搜索箱与客户端四边形都有界 |
| `entity_reach` 是 NaN / Infinity（属性被别的模组写坏） | 半径 0：打不中，也不画环 |
| 半径算出来 ≤ 0（负数 reach） | 同上，0 |
| 客户端收到坏包（非有限、超上限的半径） | 过同一道闸再画，坏值不会变成铺满屏幕的四边形 |
| 报文里的蓄力非有限 | 按满蓄力画（满不透明、满寿命）：画不画已经由半径那道闸决定，不该在这里凭空变淡 |

客户端配置里与尺寸有关的三项只改「怎么画」，不改「打多远」：

- `incursusRift.radialSpeed` / `incursusRift.lifetimeTicks` 只决定环**开多快**。把速度调成 0
  时环不会缩进花心，而是从头到尾贴在伤害边界上。
- `incursusRift.petalSize` 是环带的**厚薄**（基准半边，默认 2.5；按 4.27 格的半径标定），
  实际半边按本次半径等比缩放。想更细就往下调，想厚重就往上调，都不影响半径。
- `incursusRift.intensity` 是整层的浓淡（默认 1.0）。

## 回归用例

`IncursusSwingReachTest`（JUnit）钉住半径公式、6 格封顶、退化输入折 0、最近点判定与搜索箱；
`IncursusRiftGeometryTest`（JUnit）钉住「末帧花瓣中心落在半径上」与「蓄力只改薄厚/寿命」。
两边读的是同一个半径，改错任何一条都会同时打脸命中与观感。
