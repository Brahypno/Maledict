# 神侵恶刃的出手频率

**一次按下 = 一刀。** 按住左键（包括对着方块按住）不会连续出刀：

| 操作 | 结果 |
| --- | --- |
| 点一下 | 一刀，本体伤害按当时的蓄力缩放 |
| 按住（方块或空处） | 只有按下那一下的一刀 |
| 连点 | 一次点击一刀，本体伤害按每次点击时的蓄力 |

## 以前为什么会连出

Forge 把这个点击事件插进了两个地方：一次按下走 `Minecraft#startAttack`（真正的点击），
按住左键对着**非空气方块**时走 `Minecraft#continueAttack`（持续破坏那条每 tick 一次的路径）。
客户端把这个事件当作出手请求，于是「按住方块」变成每 tick 一个出伤包；服务端只挡同一个 gameTime
里的重复包，上限 20 刀/秒。

现在按住期间重复来的事件只压掉原版出手——不发包、不摆手、也不清蓄力；按下锁在攻击键抬起时解除。
只有真正出手那一下才摆手并清本地蓄力，所以蓄力条照常读得出来。

## 出伤层没有频率闸

这是有意的，不是遗漏：**恶刃无视 i-frame 是特权**。奥术那一跳会先把 `invulnerableTime` 清零再追加
（见 [incursus-blade-channels.md](incursus-blade-channels.md)），霜冻与奥术也都不按攻击强度缩放。
为了降频去加「最小出手间隔」之类的东西，等于把特权削掉，不是修 bug。

由此得到的推论，按设计接受：

- **真实点击速率直接决定 DPS。** 刀速 0.7 次/秒只决定蓄力条多久回满，不限制你能不能点——轻点出弱刀是
  原版规则。本体缩放 `0.2 + 0.8 × 蓄力²`（满蓄力 0.7×base/秒，蓄力 0.5 时 1.4 刀/秒只有 0.56×base/秒），
  但通道每刀全额，所以本体与通道量级相当时，连点的总 DPS 高于等蓄力。这是两条特权叠出来的已知后果。
- 改包伪造高频请求属于作弊，和任何模组一样，不在这条机制的管辖里。

## 数值一览

| 项 | 值 |
| --- | --- |
| 刀速 | 玩家基础 `ATTACK_SPEED` 4.0 + 刀自己的 `-3.3` = **0.7 次/秒** |
| 一刀蓄力周期 | `20 / 0.7 ≈ 28.6 tick` |
| 按住时的上限 | **一刀/次按下** |
| 本体每刀 | `本体伤害 × (0.2 + 0.8 × 蓄力²)` |
| 霜冻/奥术每刀 | 全额，不缩放 |

## 不变的东西

- 按住方块时原版挖方块依旧被压掉（点击事件照旧 cancel），与改动前一致。
- 半径、命中判定、一次挥砍一轮探测、投掷/飞升/飞镰的入口都不受影响。
