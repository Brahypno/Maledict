# 扬弃逐光 5 级：恶刃的连带一刀

四件护甲 + 主手神侵恶刃 + 一把斧凑到 **5/6** 时，恶刃的近战挥砍会顺着「从属」这条线多砍一个人：
**打中的生物如果认主，主人也吃下同一刀的等额伤害。**

这条效果与同一档的「武器攻击更加真实」（轻档探针补满）共用一个门禁，护甲提示里也只有那一行
`5：武器攻击更加真实`，没有单独的说明行。

## 触发条件

| 条件 | 口径 |
| --- | --- |
| 件数 | ≥5：四件护甲穿在四个护甲栏，神侵恶刃拿在**主手** |
| 攻击 | 只认恶刃自己的近战挥砍 `IncursusBladeAttack#perform`，主伤害与横扫到的每一个目标都算 |
| 不算的攻击 | 投掷镰刀（回旋返程）、飞升裂隙横扫、右键技能、任何别的伤害来源 |
| 被打者 | 必须是 `OwnableEntity`（原版驯服的宠物，以及其他模组认主的随从 / 召唤物） |
| 主人 | 按被打者自己的 `getOwnerUUID()` 现查，**只在被打者所在的维度里**找；主人已死或不在这个世界里就当没有主人 |
| 自己打自己的宠物 | 没有豁免：主人正好是攻击者本人时，这一刀照样打在自己身上 |

## 同一把刀

主人挨的那一记不是新造的东西：它就是和被打者完全相同的那次调用 ——
`IncursusBladeAttack#applyScytheMeleeDamage`，伤害类型 `SCYTHE_MELEE`、攻击者是同一名玩家、
伤害值就是这一刀的数值、连补满开关都一致。因此：

- 没有新的伤害类型、没有数据包条目、没有语言键，死讯就是这把刀的死讯；
- 主人的护甲、附魔、抗性、吸收、灵魂护盾照常算，无敌帧也照常拦 —— 和任何被这把刀砍到的目标一样，
  不为主人开特例，也不额外穿透；
- 刀上喂了精魂时，冻结 / 奥术两条属性通道跟着这一记主伤害照常派发，主人在自己这边也会吃到一份。

## 认不了的「主人」

只认 `getOwnerUUID()`。因此：村民与傀儡、没有 UUID 归属的召唤物、以及主人已经离开这个维度的
生物，都不会把伤害转出去。跨维度不追 —— 主人的伤害不会去加载另一个维度。

## 实现落点

| 位置 | 作用 |
| --- | --- |
| `LightwardSet#unlocksWeaponTopUp` | 整次挥砍唯一的 5 级门禁读数，探针补满与连带共用 |
| `IncursusBladeAttack#perform` | 每记主伤害之后，对认主的被打者再调用一次 `applyScytheMeleeDamage` |
| `IncursusBladeAttack#ownerOf` | 按 UUID 认主，同维度解析，主人已死不转 |

多部位 Boss 会先按活体根折叠成一条命（`uniqueLivingTargets`），所以「一条命一刀」仍然只连带一次。

回归用例：`LightwardTransferTest`（GameTest，批次 `lightward_transfer`）钉住 —— 只拿刀不凑五件时主人
一点不疼；四件护甲 + 主手刀时主人真的挨了这一记（伤害类型是 `SCYTHE_MELEE`、数值与被打者相同）、
掉血完全相等，且冻结 / 奥术通道对两边派发的次数一致。
