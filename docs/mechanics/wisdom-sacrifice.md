# 牺牲仪式与渡鸦取眼

「献祭」是一笔要还的账：仪式按上印记，之后每分钟自己掉 6 点，九天九夜共 180 次、1080 点。
账有两条结清路线 —— **自己熬到期**，或者**被渡鸦把眼睛啄下来一次收清**。

## 印记

| 项 | 值 |
| --- | --- |
| 仪式 | Malum 灵魂图腾上的 `sacrifice_rite`，符文木那一半是空效果 |
| 选中范围 | 图腾四周 16 格（AABB） |
| 条件 | 主手握着提尔锋；还没拿过「智慧的牺牲」 |
| 时长 | 216000 tick，九天九夜 |
| 出手 | 每分钟一次，固定 6 点（等级不参与结算） |
| 总账 | 180 次，1080 点 |
| 伤害 | `malum:voodoo`：穿护甲、穿抗性提升、穿创造模式免疫，结算时单独让过无敌帧 |
| 死讯 | 没有攻击者，所以是 Malum 那句「灵魂被击碎」，不会把任何人记成凶手 |

实际时长被缩短或倒计时被加速，只提高出手频率，不改单次伤害，也不看实际掉了多少血。
凭空来的印记（`/effect give`、别的模组塞的）没有仪式凭据，两条路线都不发成就。

## 路线一：熬到自然到期

进度随实体 NBT 保存：第一 tick 就出手，之后把 180 次均匀铺在实际时长里，跳过的节点到期时补上。
自然到期那一刻补足尾段，玩家还活着、凭据还在，就发「智慧的牺牲」。
中途死亡、喝牛奶、`/effect clear` 或被别的模组摘掉都只是白挨一顿打。

## 路线二：渡鸦取眼（`WisdomSacrifice#settleByRaven`）

成年渡鸦闲逛时，看见八格以内**戴着仪式印记**的玩家就会飞过去，贴着脑袋把眼睛啄下来，把剩下的次数
一次结清。

| 条件 | 口径 |
| --- | --- |
| 起手距离 | 8 格，且视线通畅；不需要先把他当攻击目标 |
| 放弃距离 | 跟到 16 格还没够到就放掉 |
| 下嘴距离 | 鸦眼到人眼 1.6 格 —— 得贴着脑袋，站在脚边够不到 |
| 印记 | 必须是仪式按上的那枚（凭据在），`/effect give` 来的不算 |
| 信任 | 不啄：只有繁殖出的雏鸟才认人（继承两位喂养者的 UUID），成年野鸟谁都不信 |
| 创造 / 旁观 | 不啄（voodoo 穿创造免疫，一啄就是一条命） |
| 次数 | 一轮仪式只结算一次；结清后印记与凭据一起摘掉 |

结算顺序是**先发成就、后结清伤害**，因为那一笔最多 1080 点穿甲伤害，人基本当场就没了；成就排在后面
尸体收不到。所以：

- 成就、+1 符文栏、+1 眼饰栏和 `maledict:bleeding_eye` 奖励都在死之前同步到账；
- 六分钟的失明 + 黑暗是下一 tick 才补挂的，只挂给还活着的人；被这一啄打死的玩家不会挂
  （重生本来也不继承效果）；
- 剩下的次数一次打出，满打满算 1080 点；挨过一半才被啄就只剩 540 点。走完或超了就是 0 点。
