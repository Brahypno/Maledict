# 测试

游戏测试与 JUnit 单元测试各自最多保留 50 项，当前各 50 项。新增用例达到上限时，替换或删除
低价值用例；不靠过滤、禁用或把旧测试藏进一个入口来压低报告数量。

本次以腐枯凋灵命中/重聚状态序列替换简单武器抬档断言，以遗迹触发场景替换维度常量场景，数量仍各为 50。
巨匠唤醒以实际星星消耗、重入与存档场景替换倒吊者纯阶段NBT检查；以完整动画资产的抬头、张口和碰撞高度检查替换姿态复制检查，数量仍各为50。
同一巨匠游戏场景还检查石头/黑曜石墙的实际拆除穿越、蜘蛛网清除、凋灵免疫、Forge取消、mobGriefing关闭及地面保留；沿用原有用例，不增加测试数量。
巨匠场景继续验证唤醒降雨、激光遮挡与静默、雨滴穿过完整屋顶、头尾重叠在每tick合并探针调用，以及真实AI进入三种招式；动画用例检查昂首冲撞和张口吼叫，数量不增加。
同一场景还检查10护甲、3%单次上限、400/600/800生命池、按比例缩放的伤害和防止玩家二次难度缩放，并确认Malum运行时载入四种精魂数据；动画用例同时核对6/7/8/3的生成数量。
巨匠伤害通过简单LIGHT、普通MEDIUM、困难FINAL且均不追伤；同一场景用减伤目标检查三个档位只命中一次、不补足差额，按用户确认不再要求入口过滤无敌帧。
巨匠动画用例继续验证各蛇行相位下的招式首尾连续、身体相位保留、冲撞加减速和静止呼吸；游戏场景在真实地面上检查28格以内的冷却移动和蛇行相位推进，测试数量不增加。
同一用例检查激光与实际头部朝向一致（含背后、侧面和±180°转向），以及泪雨的水平五格起手、起手后离开仍施法、固定圆盘落区与登场例外；地面冷却移动要求35tick内超过2格。
巨匠断尾按75/50/25%各失去4节、只减不增，并以编舞数据核对剩余地面蛇身不少于8格的上限（25%时断到11节上限）；同一游戏场景再用三次强制击杀验证死亡时断到上限并掉落一枚“光的残片”。
拘魂仪式以真实灵魂木/符文木图腾、首次击杀绑定、主手属性事件和解除替换渡鸦合成台阶繁殖用例，数量仍为50。
同一场景另核对精魂音效的解析顺序：铁傀儡走显式表取到 `entity.iron_golem.attack`（而不是它的受击声），
僵尸没有 `entity.zombie.attack`，于是封印时把受击声 `entity.zombie.hurt` 记进 `SoundId`。

所有测试在 `src/test`，项目根目录显式执行：

```powershell
.\gradlew.bat test
.\gradlew.bat test --tests '*DamageAdaptationTest'   # 只跑一个类
```

测试包跟随生产代码：`common/raven`、`common/vicissitude`（含 `rig`、`rite`、`curio`）、
`common/weapon`（`incursus`、`lover`、`remembrance`）、`common/rune`、`common/curio`、
`common/wisdom` 等。跨功能伤害适应算法在 `common/combat`；客户端测试跟随各自的功能包。

`test` 先用已有 `runGameTestServer` 配置启动真实 Forge 服务端，运行同一目录中标注 `@GameTest` 的实体场景；
随后执行 JUnit 逻辑用例。没有独立 GameTest 目录或 source set，测试内容不会打入正式包。
`--tests` 只过滤 JUnit 用例；游戏场景仍会执行。游戏报告保存在 `build/tests/game-environment.log`，
不会被随后初始化 Minecraft 日志的 JUnit 用例覆盖。

`check` 与 `build` 不依赖 `test`，不会自动跑测试。JUnit HTML 报告在 `build/reports/tests/test/index.html`，
首次运行需要下载测试依赖，缓存齐全后可以加 `--offline`。

JUnit 公式断言只证明被调用的生产函数满足断言；实体场景另在真实 Forge 世界中验证执行链。
JUnit 只执行一次；Forge 场景直接验证实体和事件流程，不再嵌套启动 JUnit 重跑同一组断言。

保留各功能的代表性场景，删去重复组合、简单常数与低价值边界用例：

| 范围 | 保留的重点 |
| --- | --- |
| 伤害适应 | 两消息与三消息轮换、最近命中顺序、淘汰清账、同 tick 去重与倍率复用、NBT 往返 |
| 无常 Boss | 旁观者与创造模式、1500 血量和旧账本、虚拟武器重载、实际适应存档、部位命中、挥砍高度隔离、世界脱困 |
| 血量与饰品 | 存档保留伤口、取消伤害与死亡、嵌套伤害、三次强制击杀、护甲与吸收后的批次扣血、原槽返还、依赖栏位、放箱失败重试 |
| 其他世界交互 | 属性转换、倒吊者传送与反弹、女祭司延迟伤害与灵魂转移、祈唤支付与退款、渡鸦火中逃生、维度与配对井口、矿物掉落合成、武器与献祭、拘魂仪式主流程 |
| 客户端与纯逻辑 | 姿态与矩阵缓存、网格边界、选曲、微光迟滞、提示框极小尺寸、延迟池、渡鸦行为及献祭进度 |

Curios 场景使用真实 capability、装备事件与栏位属性。FakePlayer 不会自动更新装备，测试显式投递
`LivingTickEvent` 并等待栏位更新。渡鸦火中逃生与拘魂仪式均使用人工场地；拘魂仪式在 FakePlayer 上
直接授予进度并验证事件链，不代表真实客户端操作。服务端测试不验证实际画面、客户端同步、操作手感或游戏内帧率。
